# 抑菌圈检测系统 - 用户使用指南

## 🖥️ 界面概览

本GUI界面采用现代化的暗色主题设计，包含以下主要功能区域：

- **左侧控制面板**：文件操作、检测器选择、参数设置、检测控制
- **右侧显示区域**：检测结果可视化、结果统计、详细数据表格

## 🚀 快速开始

### 环境要求

- Python 3.8 或更高版本
- PyQt6
- OpenCV-Python
- NumPy

### 安装依赖

```bash
cd opencv-circle-detection
pip install -r requirements.txt
```

### 运行程序

#### 单张图像处理
```bash
python gui/standalone_gui.py
```

#### 批量处理
```bash
python run_batch_processing.py
```

## 📋 详细使用指南

### 1. 单张图像处理

#### 步骤1：打开图像
- 点击"打开图像"按钮
- 选择要分析的抑菌圈图像文件
- 支持格式：JPG、PNG、BMP、TIFF

#### 步骤2：选择检测器
根据您的样本类型选择合适的检测器：

- **原始检测器（适合滤纸片）**：
  - 在滤纸片检测上表现优秀 (3/3 ✅)
  - 推荐用于滤纸片法抑菌圈检测

- **修正检测器（适合挖孔）**：
  - 在透明挖孔检测上有改进 (3/4 👍)
  - 推荐用于挖孔法抑菌圈检测

#### 步骤3：参数设置

##### 基本参数
- **培养皿直径**：标准培养皿直径，默认90mm
- **滤纸片直径**：滤纸片直径，默认6mm
- **挖孔直径**：挖孔直径，默认6mm

##### 检测模式
- **自动检测**：系统自动判断抑菌物质类型
- **滤纸片**：专门检测滤纸片类型的抑菌物质
- **透明挖孔**：专门检测透明挖孔类型的抑菌物质

#### 步骤4：开始检测
- 点击"开始检测"按钮
- 系统将依次进行：
  1. 培养皿检测与尺寸标定
  2. 抑菌物质识别
  3. 抑菌圈边界检测
- 检测过程中显示进度条

#### 步骤5：查看结果

##### 检测结果标签页
- 可视化显示检测结果
- 绿色圆圈：培养皿边界
- 彩色圆圈：抑菌物质位置
- 黄色圆圈：抑菌圈边界

##### 结果统计标签页
- 培养皿信息（中心坐标、半径、直径）
- 标定比例（像素/毫米）
- 抑菌物质列表
- 抑菌圈测量数据

##### 详细数据标签页
- 完整的数值数据表格
- 支持复制和导出

#### 步骤6：保存结果
- 点击"保存结果"按钮
- 选择保存目录
- 系统将保存：
  - 标注后的结果图像 (`*_result.jpg`)
  - 详细测量数据 (`*_data.txt`)

### 2. 批量处理

#### 步骤1：添加文件
- **添加图像文件**：选择单个或多个图像文件
- **添加文件夹**：自动扫描文件夹中的所有图像文件
- **文件管理**：显示待处理文件列表，支持移除选中文件

#### 步骤2：配置参数
- **培养皿直径**：设置标准培养皿直径
- **物质类型**：选择检测模式
- **输出目录**：选择结果保存位置
- **保存选项**：
  - 保存标注图像
  - 保存检测数据
  - 生成汇总报告

#### 步骤3：开始批量处理
- 点击"开始批量处理"
- 实时查看处理进度和结果
- 可随时点击"停止处理"中断

#### 步骤4：查看批量结果
- 结果表格显示每个文件的处理情况
- 输出目录包含所有保存的文件
- 汇总报告提供整体统计信息

## 🎯 最佳实践

### 检测器选择建议

根据测试结果：

| 样本类型 | 推荐检测器 | 检测效果 | 适用场景 |
|---------|-----------|---------|---------|
| 滤纸片法 | 原始检测器 | 3/3 ✅ | 滤纸片比背景明显更亮 |
| 透明挖孔法 | 修正检测器 | 3/4 👍 | 透明挖孔需要排除气泡干扰 |
| 混合或未知 | 自动检测 | 根据检测结果选择 | 让系统自动判断 |

### 参数优化技巧

#### 培养皿检测优化
- 确保图像中培养皿占据大部分区域
- 避免图像边缘截断培养皿
- 调整培养皿直径参数匹配实际尺寸

#### 抑菌物质检测优化
- **滤纸片**：确保良好的光照条件，避免阴影
- **透明挖孔**：注意区分气泡和真实挖孔
- **混合场景**：使用自动检测模式

#### 图像质量要求
- **分辨率**：建议不低于1000x1000像素
- **光照**：均匀光照，避免强烈阴影
- **对比度**：确保抑菌物质与背景有足够对比
- **清晰度**：避免模糊和失焦

## 🐛 常见问题解决

### Q: 程序无法启动
A: 请确保已安装所有依赖包：
```bash
pip install PyQt6 opencv-python numpy
```

### Q: 图像加载失败
A: 
- 检查图像文件格式是否支持
- 确认文件路径中没有特殊字符
- 尝试使用其他图像文件

### Q: 检测结果不准确
A: 
- 尝试调整检测器类型
- 检查参数设置是否正确
- 确保图像质量足够清晰
- 参考检测器选择建议

### Q: 进度条卡住
A: 
- 图像过大可能导致处理时间较长
- 等待检测完成或重启程序
- 尝试使用较小尺寸的图像

### Q: 批量处理中断
A:
- 检查输出目录是否有写入权限
- 确认所有图像文件都可以正常读取
- 查看错误信息，移除有问题的文件
