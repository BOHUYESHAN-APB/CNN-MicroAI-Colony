## 系统概述

本系统是一款集成了菌落计数和抑菌圈检测功能的专业软件，采用现代化的界面设计，支持多种检测算法，能够满足实验室日常检测需求。

### 主要功能
- 菌落自动计数
- 抑菌圈测量分析
- 数据统计和报告生成
- 图像存档管理

## 软件安装

1. 系统要求：
   - Windows 7/10/11 操作系统
   - 4GB 以上内存
   - 500MB 可用磁盘空间

2. 安装步骤：
   - 安装Python 3.9或更高版本
   - 安装所需依赖：`pip install -r requirements.txt`
   - 运行程序：`python main.py`

## 界面说明

主界面分为三个区域：

1. 左侧资源管理器
   - 文件浏览和选择
   - 历史记录查看
   - 项目管理

2. 中央图像显示区
   - 图像预览
   - 实时检测结果显示
   - 标注工具

3. 右侧分析面板
   - 检测结果统计
   - 测量数据显示
   - 报告预览

## 基本操作

### 图像导入
1. 点击"打开图像"按钮
2. 通过资源管理器选择
3. 拖拽文件到程序窗口

### 抑菌圈检测
1. 导入培养皿图像
2. 点击"开始检测"按钮
3. 等待检测完成
4. 查看检测结果

### 数据管理
1. 设置保存目录
2. 选择文件名前缀
3. 导出分析结果
4. 生成分析报告

## 高级功能

### 手动标注
1. 选择"添加标注"功能
2. 点击需要标注的位置
3. 输入标注文本
4. 确认添加

### 测量校准
1. 设置标准培养皿尺寸
2. 进行自动校准
3. 确认校准结果

### 批量处理
1. 选择多个图像文件
2. 设置处理参数
3. 开始批量处理
4. 查看处理结果

### 数据导出
1. PDF报告导出
2. Excel数据表导出
3. 图像结果导出
4. 原始数据导出

## 常见问题

### 检测问题
1. 检测失败
   - 检查图像质量
   - 确保光照均匀
   - 调整检测参数

2. 结果不准确
   - 进行图像校准
   - 调整检测阈值
   - 使用手动标注

### 系统问题
1. 程序无法启动
   - 检查Python环境
   - 确认依赖安装
   - 查看错误日志

2. 性能问题
   - 关闭其他程序
   - 检查系统资源
   - 减小图像大小
