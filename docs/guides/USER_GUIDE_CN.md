# 菌落分析系统用户指南

## 简介

菌落分析系统是一款专业的图像分析工具，用于自动检测和计数培养皿中的菌落。本系统支持实时相机预览、自动分析、数据导出等功能。

## 主要功能

1. 实时相机预览和拍摄
2. 自动菌落检测和计数
3. 数据分析和可视化
4. 结果导出和分享

## 快速开始

### 1. 启动应用

- 双击应用图标启动程序
- 等待系统初始化完成

### 2. 拍摄图像

1. 点击底部中央的相机按钮进入拍摄界面
2. 调整培养皿位置，确保完全在取景框内
3. 观察水平仪指示：
   - 绿色边框表示倾斜度在5度以内
   - 红色边框表示需要调整角度
4. 点击拍摄按钮capture照片

### 3. 分析图像

1. 拍摄完成后自动进入分析界面
2. 等待系统自动分析（通常需要几秒钟）
3. 查看分析结果：
   - 菌落总数
   - 位置标记
   - 大小分布
   - 置信度指标

### 4. 导出结果

支持多种导出格式：
- JSON格式（原始数据）
- CSV/Excel（表格数据）
- PDF报告（包含图片和分析）
- Markdown文档

## 常见问题

### 1. 拍摄问题

**Q: 为什么边框一直显示红色？**
A: 检查设备是否平放，调整拍摄角度直到水平仪显示在±5度范围内。

**Q: 图像模糊怎么办？**
A: 确保相机镜头清洁，保持设备稳定，适当调整焦距。

### 2. 分析问题

**Q: 检测结果不准确？**
A: 检查光线条件，确保图像清晰，必要时调整分析参数。

**Q: 分析速度慢？**
A: 可能是由于图像分辨率过高或系统资源不足，尝试调整设置。

### 3. 导出问题

**Q: 无法导出文件？**
A: 检查存储权限和空间是否充足。

**Q: 导出的PDF无法打开？**
A: 确保安装了PDF阅读器，检查文件是否完整。
