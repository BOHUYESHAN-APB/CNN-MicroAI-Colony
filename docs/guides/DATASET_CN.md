# 数据集说明

## 演示模型数据集

本软件中包含的演示模型使用AGAR数据集训练：

- **数据集名称**：AGAR（用于自动识别的标注菌落数据集）
- **许可证**：知识共享署名-非商业性使用 2.0 通用许可证 (CC BY-NC 2.0)
- **来源**：https://agar.neurosys.com/
- **用途**：仅用于学术研究和演示目的

### 数据集详情
- 细菌菌落的高分辨率显微图像
- 多种培养条件和生长阶段
- 详细的菌落数量和位置标注

## 生产数据集

生产数据集由云南农业大学农业与生物技术学院本科生团队开发和维护：

### 数据采集标准
- 分辨率：支持20MP和8MP图像
- 背景：标准化Pantone色彩校准板
- 光照：多种条件（明场、暗场、荧光）

### 数据类别
1. **细菌菌落**
   - 标准培养平板
   - 不同生长阶段
   - 多种细菌种类

2. **药敏测试**
   - 抑菌圈测量
   - 多种抗生素类型
   - 时间序列观察

3. **形态特征**
   - 菌落形状和花纹
   - 颜色变化
   - 生长特征

### 未来扩展
1. **野生真菌识别**
   - 宏观形态学
   - 生境信息
   - 安全分类

2. **临床微生物分析**
   - 病原体识别
   - 抗生素耐药模式
   - 生长速率分析

## 数据采集指南

### 图像采集要求
1. **设备**
   - 实验室用高分辨率相机（20MP）
   - 野外工作用便携相机（8MP）
   - 标准色彩校准板

2. **环境**
   - 受控光照条件
   - 温度：20-25°C
   - 湿度：40-60%

3. **文档记录**
   - 样本元数据记录
   - 生长条件参数
   - 时间和日期标记

### 质量控制
1. **图像质量**
   - 焦点和清晰度检查
   - 色彩校准验证
   - 分辨率验证

2. **标注标准**
   - 双盲验证
   - 专家审查流程
   - 版本控制
