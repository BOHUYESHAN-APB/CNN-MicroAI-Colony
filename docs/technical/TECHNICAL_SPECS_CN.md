# 技术规格说明

## 系统要求

### 硬件要求
1. **处理器**
   - CPU：Intel Core i5 8代或同等性能
   - 内存：最低8GB，建议16GB
   - GPU：NVIDIA GeForce GTX 1660或同等性能（可选）
   - 存储：软件500MB，数据10GB以上

2. **图像采集要求**
   - 相机：最低8MP，建议20MP
   - 支持UV/IR成像（可选）
   - 色彩校准功能

### 软件要求
1. **操作系统**
   - Windows 10/11（64位）
   - 计划未来支持Linux/macOS

2. **依赖项**
   - Python 3.8或更高版本
   - CUDA 11.0+（GPU加速）
   - OpenCV 4.5+
   - PyQt5
   - PyTorch 1.9+

## 核心功能

### 图像处理
1. **输入支持**
   - 多种图像格式（JPG、PNG、TIFF）
   - 批量处理能力
   - 多分辨率支持（8MP-20MP）
   - UV/IR光谱支持

2. **分析功能**
   - 菌落检测和计数

3. **输出选项**
   - CSV/Excel导出
   - JSON数据格式
   - PDF报告
   - 统计可视化

### 用户界面
1. **主要组件**
   - 图像列表管理
   - 分析参数配置
   - 实时预览
   - 结果可视化

2. **可视化工具**
   - 分布直方图
   - 计数序列图
   - 置信度分布
   - 多图对比

3. **数据管理**
   - 基于项目的组织
   - 结果历史追踪
   - 数据导入导出
   - 批量操作支持
