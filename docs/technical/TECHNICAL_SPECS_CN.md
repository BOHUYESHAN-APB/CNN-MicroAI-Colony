## 2. 检测算法

### 2.1 培养皿检测
- 算法：改进的霍夫圆检测
- 参数配置：
  ```python
  params = {
      'dp': 1,
      'minDist': 400,
      'param1': 50,
      'param2': 35,
      'minRadius': image.shape[0]/3,
      'maxRadius': image.shape[0]/1.8
  }
  ```
- 预处理：高斯模糊 (kernel_size=9, sigma=2)
- 精确度：>95% (标准环境下)

### 2.2 菌落检测
采用三重检测策略：

1. HSV色彩空间检测
   - 提取V通道
   - CLAHE对比度增强
   - 自适应阈值分割

2. 自适应阈值方法
   - 多尺度块大小(25,51,75)
   - 高斯权重
   - 梯度辅助判断

3. 梯度检测方法
   - 多尺度Sobel算子
   - 局部标准差分析
   - OTSU阈值

### 2.3 抑菌圈分析

1. 主抑菌圈检测
   - 阈值范围：35-180
   - 面积比例：>0.8倍滤纸片面积
   - 圆形度验证：>0.7
   - 测量精度：±0.1mm

2. 次级抑菌圈检测
   - 阈值范围：65-160
   - 面积比例：>0.6倍滤纸片面积
   - 圆形度验证：>0.5
   - 测量精度：±0.2mm

3. 重叠区域分析
   - 形态学处理优化
   - 最小面积过滤：50px²
   - 区域验证算法
   - 面积计算精度：±1mm²

### 2.4 浮点数精度
- **主要精度**: 模型训练和推理过程主要使用标准的 FP32 (单精度浮点数)。
- **TF32 加速**: 在兼容的 NVIDIA Ampere 及更新架构的 GPU 上，部分训练脚本 (例如 [`models-colony-counting/in-use/main_models_train/train.py`](models-colony-counting/in-use/main_models_train/train.py:21-22)) 会启用 TF32 (TensorFloat-32) 精度，以利用硬件加速提升训练效率，同时尽可能保持与 FP32 相近的数值范围和准确性。
- **低精度支持**: 目前的项目代码中，没有发现明确将模型或数据转换为 FP16 (半精度浮点数) 或 FP8 等更低精度的操作。

## 5. 数据处理

### 5.1 数据格式
```json
{
    "petri_dish": {
        "center": [x, y],
        "radius": r,
        "diameter_mm": 90.0
    },
    "colonies": [
        {
            "center": [x, y],
            "radius": r,
            "primary_zone": [x, y, r],
            "secondary_zone": [x, y, r],
            "overlap_zones": [[x, y, r], ...]
        }
    ]
}
```

### 5.2 测量数据
- 尺寸单位：毫米(mm)
- 面积单位：平方毫米(mm²)
- 小数位数：1位
- 数据存储：UTF-8编码JSON
