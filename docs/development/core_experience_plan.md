# MicroAI Colony 核心体验优化路线图

> 更新日期：2025-10-09

## 目标综述

- **提升现场可用性**：推理完成后即时可见结果、失败有反馈、统计数据准确。
- **持续演进基础**：明确短中长期交付节奏，为后续多模型、导出、硬件自适应等功能预留接口。
- **统一视觉语言**：逐步引入更具 iOS/Fluent 质感的浅色卡片与暗色背景混搭风格。

## 阶段规划

### 阶段 1 · 核心体验（当前进行中）

- [x] 推理结果结构化输出，包含标注图与检测列表。
- [x] 主界面实时展示检测数、置信度 Top3，并预览最新标注图。
- [x] 统计面板只计入原始/导入图片，解决“图片数膨胀”问题。
- [ ] 推理失败/未检测提示与引导（toast、日志导出按钮高亮）。
- [ ] 历史结果快速查看：预览图点击打开详情页，支持左右滑动切换（进行中，已完成单张打开）。

### 阶段 2 · 视觉与交互提升

- 设计语言迭代：顶部仪表卡片、底部浮动操作栏、Material 3 动画。
- 主题与配色：定义夜间主色、对比色及渐变背景，统一圆角半径。
- 等待态优化：推理加载使用 Lottie/Progress Indicator，提供“取消”操作。

### 阶段 3 · 智能引擎与数据闭环

- 硬件探测：GPU/NPU/CPU 能力检测、测速与持久化，自动选择最优引擎。
- 多模型管理：无量化/量化模型共存，支持项目维度的模型切换。
- 数据导出：一键打包原始图、裁剪图、标注图、CSV/Excel 统计、运行日志。
- 报告中心：生成项目检测报告（成功率、平均时延、失败案例）。

## 参考实现提示

- **数据结构**：保持 `OnnxHelper.InferenceResult` 可扩展，未来可挂载关键点、掩码等附加信息。
- **UI 预览**：预留缩略图容器（RecyclerView）接口，后续可扩展为时间轴或批量操作入口。
- **导出能力**：日志/图片路径统一走 `ProjectRepository`，便于 Zip 打包。
- **测试策略**：阶段 1-2 以手动回归 + 日志核对为主，阶段 3 引入自动化截图/性能检测脚本。
