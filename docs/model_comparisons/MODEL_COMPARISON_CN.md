# 菌落检测模型对比分析

## 当前模型(Faster R-CNN + ResNet50)效果

### 场景识别率  
| 场景类型 | 识别率范围(%) | 主要挑战 |
|---------|------------|--------|
|标准微生物平板|>98|无|
|质量略差或低像素|95-98|分辨率不足|  
|黏连菌落|85-92|分割算法失效|
|边界模糊或培养基壁|<80|特征提取困难|  
|高密度黏连菌落|<80|漏检率高|

### 核心缺陷对比  
|模块|现有方案|预测优化方案|专利风险|
|----|-------|-----------|-------|
|检测精度|MAE 5.2%|MAE ≤3.5%|高|
|形态学鉴别|88%|≥92%|中|  
|预处理流程|传统算法|深度学习分割|高|
|推理速度|420ms/帧|110ms/帧|-|
