🔧 技术细节面板

ResNet50层级结构

Conv1: 7×7, 64, stride=2
MaxPool: 3×3, stride=2
Layer1: [1×1,64; 3×3,64; 1×1,256]×3
Layer2: [1×1,128; 3×3,128; 1×1,512]×4
Layer3: [1×1,256; 3×3,256; 1×1,1024]×6
Layer4: [1×1,512; 3×3,512; 1×1,2048]×3

FPN特征融合

P6: MaxPool(P5)
P5: 1×1 conv(2048→256)
P4: 1×1 conv(1024→256) + upsample
P3: 1×1 conv(512→256) + upsample
P2: 1×1 conv(256→256) + upsample

训练配置

优化器: AdamW
学习率: 0.0001
权重衰减: 0.05
梯度裁剪: L2=35
混合精度: FP16
训练周期: 12 epochs
