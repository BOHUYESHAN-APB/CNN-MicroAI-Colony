核心技术细节补充：
  • 抑菌圈检测支持滤纸片与透明圈两种类型，参数自适应，亮度/标准差/圆度多重验证。
  • 滤纸片检测采用高斯模糊+霍夫圆+亮度/标准差阈值，透明圈检测采用反色+低阈值+圆度判别。
  • 完整流程包括培养皿检测、物质类型判别、虚拟中心点补偿、抑菌圈ROI提取与圆形拟合。
  • 小数据集模型采用骨干冻结、anchor缩放、数据增强等策略提升泛化。
  • 大数据集模型支持FP16混合精度与分布式训练，提升效率与精度。
  • 所有核心部件均基于Apache 2.0协议，依赖PyTorch、OpenCV、MMDetection等主流开源组件。

最佳实践：根据场景自动选择检测器，避免过度复杂的边缘检测，优先保证参数调优与场景适配。
