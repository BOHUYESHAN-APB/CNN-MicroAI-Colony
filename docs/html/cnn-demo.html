CNN深度学习模型

本系统采用Faster R-CNN、YOLOv8等主流深度学习目标检测框架，结合微生物领域专用数据增强与小样本优化策略，实现高精度菌落检测与抑菌圈自动计数。

模型特点

高精度检测

支持多类别菌落识别，复杂场景适应性强，准确率≥99.2%，误差≤0.5mm。

优化策略

采用小样本优化、数据增强、迁移学习等技术，提升模型泛化能力。

端到端处理

从图像预处理到结果输出，全流程自动化，支持24/7无人值守运行。

灵活扩展

支持多种深度学习框架，可扩展至其他微生物检测任务。

模型详情

Faster R-CNN + ResNet50

基于区域建议网络的两阶段检测器，适合高精度菌落检测任务。采用ResNet50作为主干网络，结合FPN特征金字塔网络，支持多尺度检测。

输入尺寸 800×800
类别数 10+
训练数据 5000+标注
优化器 SGD + 余弦退火
主干网络 ResNet50 + FPN
检测头 RPN + RoI Heads

YOLOv8 系列

单阶段检测器，平衡速度与精度，支持实时检测需求。采用anchor-free设计，减少超参数数量，提升检测效率。

输入尺寸 640×640
类别数 10+
训练数据 3000+标注
优化器 AdamW + 余弦退火
网络结构 CSPDarknet + PAN
损失函数 CIoU + BCE

技术架构

系统采用模块化设计，分为前端、后端和AI模型三大部分：

前端界面

基于React和Tauri，提供用户友好的交互界面，支持拖拽上传、实时预览、结果可视化。

后端服务

使用FastAPI实现高效的API服务，支持并发处理、缓存优化、异步任务队列。

AI模型

支持PyTorch、TensorFlow等多种深度学习框架，可灵活切换和扩展模型。
