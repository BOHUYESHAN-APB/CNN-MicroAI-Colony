# 菌落检测分析系统

![项目图标](docs/image/logo.png)

## 项目简介

开放源代码的菌落检测分析系统，基于深度学习技术实现高精度菌落计数和形态分析。

## 快速开始

```bash
# 创建虚拟环境
python -m venv venv

# 激活环境
# Windows
venv\Scripts\activate
# Linux/macOS 
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 启动系统
python MICROAI-COLONY/app.py
```
