# Test Images

This directory contains test images for the Colony Counter application.

## Image Categories

1. **Bright Field**
   - High resolution (20MP)
   - Low resolution (8MP)
   - Different colony densities

2. **Dark Field**
   - UV illumination
   - Different exposure settings

3. **Test Cases**
   - Overlapping colonies
   - Different growth stages
   - Multiple species

## Directory Structure
```
test/
├── images/
│   ├── bright/       # Bright field images
│   ├── dark/         # Dark field images
│   └── challenging/  # Special test cases
└── results/          # Test results
```

## Usage
1. Use these images to test the application's functionality
2. Verify detection accuracy
3. Test edge cases
4. Validate visualization
