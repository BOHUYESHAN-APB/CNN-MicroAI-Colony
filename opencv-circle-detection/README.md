# 抑菌圈检测系统

基于OpenCV的抑菌圈检测和分析系统，支持培养皿识别、菌落检测和抑菌圈分析。

## 功能特点

- 培养皿和菌落的自动检测
- 主次抑菌圈的识别和测量
- 重叠区域分析
- 支持图像标注和测量结果导出
- 中英文界面切换
- 现代化的图形界面

## 环境要求

- Python 3.9 或更高版本
- OpenCV 4.5.0 或更高版本
- PySide6 6.0.0 或更高版本
- NumPy 1.19.0 或更高版本

## 安装说明

1. 创建并激活虚拟环境（推荐）：
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```

2. 安装依赖：
```bash
pip install -r requirements.txt
```

## 使用说明

1. 运行程序：
```bash
python main.py
```

2. 基本操作：
   - 点击"打开图像"或使用左侧资源管理器选择图片
   - 点击"开始检测"进行分析
   - 使用鼠标滚轮缩放图像
   - 右键点击添加标注
   - 点击"保存结果"导出分析报告和标注图像

3. 界面说明：
   - 左侧：资源管理器
   - 中间：图像显示区域
   - 右侧：分析报告区域

## 注意事项

- 图像分辨率建议不低于 800x800
- 培养皿应位于图像中心位置
- 确保图像光照均匀，对比度适中
