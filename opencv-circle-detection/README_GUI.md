# 抑菌圈检测系统 - 图形化界面

基于OpenCV的抑菌圈检测系统图形化用户界面，提供直观易用的操作体验。

## 🖥️ 界面预览

本GUI界面采用现代化的暗色主题设计，包含以下主要功能区域：

- **左侧控制面板**：文件操作、检测器选择、参数设置、检测控制
- **右侧显示区域**：检测结果可视化、结果统计、详细数据表格

## 🚀 快速开始

### 环境要求

- Python 3.8 或更高版本
- PyQt6
- OpenCV-Python
- NumPy

### 安装依赖

```bash
cd opencv-circle-detection
pip install -r requirements.txt
```

### 运行程序

```bash
python main_gui.py
```

## 📋 使用指南

### 1. 打开图像
- 点击"打开图像"按钮
- 选择要分析的抑菌圈图像文件
- 支持格式：JPG、PNG、BMP、TIFF

### 2. 选择检测器
根据您的样本类型选择合适的检测器：

- **原始检测器（适合滤纸片）**：
  - 在滤纸片检测上表现优秀 (3/3 ✅)
  - 推荐用于滤纸片法抑菌圈检测

- **修正检测器（适合挖孔）**：
  - 在透明挖孔检测上有改进 (3/4 👍)
  - 推荐用于挖孔法抑菌圈检测

### 3. 参数设置

#### 基本参数
- **培养皿直径**：标准培养皿直径，默认90mm
- **滤纸片直径**：滤纸片直径，默认6mm
- **挖孔直径**：挖孔直径，默认6mm

#### 检测模式
- **自动检测**：系统自动判断抑菌物质类型
- **滤纸片**：专门检测滤纸片类型的抑菌物质
- **透明挖孔**：专门检测透明挖孔类型的抑菌物质

### 4. 开始检测
- 点击"开始检测"按钮
- 系统将依次进行：
  1. 培养皿检测与尺寸标定
  2. 抑菌物质识别
  3. 抑菌圈边界检测
- 检测过程中显示进度条

### 5. 查看结果

#### 检测结果标签页
- 可视化显示检测结果
- 绿色圆圈：培养皿边界
- 彩色圆圈：抑菌物质位置
- 黄色圆圈：抑菌圈边界

#### 结果统计标签页
- 培养皿信息（中心坐标、半径、直径）
- 标定比例（像素/毫米）
- 抑菌物质列表
- 抑菌圈测量数据

#### 详细数据标签页
- 完整的数值数据表格
- 支持复制和导出

### 6. 保存结果
- 点击"保存结果"按钮
- 选择保存目录
- 系统将保存：
  - 标注后的结果图像 (`*_result.jpg`)
  - 详细测量数据 (`*_data.txt`)

根据我们的测试结果：

| 样本类型 | 推荐检测器 | 检测效果 | 适用场景 |
|---------|-----------|---------|---------|
| 滤纸片法 | 原始检测器 | 3/3 ✅ | 滤纸片比背景明显更亮 |

## 🐛 常见问题

### Q: 程序无法启动
A: 请确保已安装所有依赖包：
```bash
pip install PyQt6 opencv-python numpy
```

### Q: 图像加载失败
A: 
- 检查图像文件格式是否支持
- 确认文件路径中没有特殊字符
- 尝试使用其他图像文件

### Q: 检测结果不准确
A: 
- 尝试调整检测器类型
- 检查参数设置是否正确
- 确保图像质量足够清晰
- 参考检测器选择建议

### Q: 进度条卡住
A: 
- 图像过大可能导致处理时间较长
- 等待检测完成或重启程序
- 尝试使用较小尺寸的图像
