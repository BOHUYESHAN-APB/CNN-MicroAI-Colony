使用指南

详细的使用说明和最佳实践

系统要求

🖥️
硬件要求
CPU: Intel i5 或 AMD Ryzen 5
RAM: 8GB 或更高
GPU: NVIDIA GTX 1060 或更高
🐍
软件环境
Python 3.7+
PyTorch 1.8+
OpenCV 4.5+
📸
图像要求
格式: JPG, PNG, TIFF
分辨率: 512×512 或更高
光照: 均匀照明

快速开始

1
环境安装

安装必要的依赖包：

pip install torch torchvision opencv-python numpy pandas matplotlib scikit-learn
2
下载模型

从GitHub或Gitee仓库下载预训练模型：

# 克隆仓库 git clone https://github.com/BOHUYESHAN-APB/CNN-MicroAI-Colony.git cd CNN-MicroAI-Colony # 下载预训练模型 python download_models.py
3
准备图像

将待分析的菌落图像放入指定目录：

# 创建输入目录 mkdir input_images # 将图像文件放入该目录 # 支持格式: .jpg, .png, .tiff
4
运行分析

执行菌落分析：

python analyze_colonies.py --input_dir ./input_images --output_dir ./results
5
查看结果

分析完成后，结果将保存在 ./results 目录中：

  • count_results.csv - 菌落计数结果
  • classification_results.csv - 菌落分类结果
  • visualizations/ - 可视化图像

高级配置

自定义参数

根据您的具体需求调整分析参数：

# 配置文件 config.yaml model: confidence_threshold: 0.8 min_colony_size: 10 max_colony_size: 1000 processing: batch_size: 32 num_workers: 4 device: 'cuda' # 或 'cpu' output: save_images: true save_csv: true generate_report: true

常见问题解决

  • 内存不足： 减小batch_size或使用CPU模式
  • 识别不准确： 调整confidence_threshold参数
  • 处理速度慢： 启用GPU加速或减少图像分辨率

使用示例

批量处理
