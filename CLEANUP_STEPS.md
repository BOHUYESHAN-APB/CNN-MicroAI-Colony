# Cleanup Steps

This document outlines the steps to clean up temporary files, cached data, and other resources created by the different versions of the Colony Detection application.

## General Steps (All Versions)

1. **Delete Temporary Files**:
   - Remove any temporary files created in the `temp` directory within each application version's directory.
   - Delete any temporary image files or processing artifacts created during analysis.

2. **Clear Caches**:
   - Clear any cached data generated by the application. This may include:
     - Processed images
     - Model outputs
     - Intermediate results
   - The specific location of cache files may vary depending on the version and configuration.

3. **Remove Logs**:
   - Delete old log files from the `logs` directory within each application version's directory.
   - Consider archiving older logs if needed for debugging or auditing purposes.

4. **Database Cleanup (if applicable)**:
   - If using a local database, remove any temporary or unnecessary data.
   - Consider creating backups before deleting data.

## Version-Specific Steps

### app-pyqt (PyQt5 Version)
1. Navigate to the `app-pyqt` directory.
2. Delete the `temp` directory and its contents.
3. Remove any files in the `results` directory that are no longer needed.
4. Clear any cached data in the `config` directory (if applicable).
5. Delete old log files from the `logs` directory.

### app-pyside6 (PySide6 Transition Version)
1. Navigate to the `app-pyside6` directory.
2. Delete the `temp` directory and its contents.
3. Remove any files in the `results` directory that are no longer needed.
4. Clear any cached data in the `config` directory (if applicable).
5. Delete old log files from the `logs` directory.

### app (New PySide6 + PyOneDark Version)
1. Navigate to the `app` directory.
2. Delete the `temp` directory and its contents.
3. Remove any files in the `results` directory that are no longer needed.
4. Clear any cached data in the `config` directory (if applicable).
5. Delete old log files from the `logs` directory.
6. **Theme-Specific Cleanup**:
    - If you have customized or modified the PyOneDark theme, ensure that any temporary or generated files related to the theme are removed. This may include compiled stylesheets or cached theme resources.

## Additional Notes

- Before performing any cleanup steps, ensure that you have backed up any important data or configurations.
- The specific file paths and directory names may vary depending on your project setup and configuration.
- Use caution when deleting files, and double-check that you are removing only temporary or unnecessary resources.
- Consider automating the cleanup process using scripts or build tools to ensure consistency and reduce manual effort.
